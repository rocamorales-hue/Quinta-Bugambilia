Integración Activa

Al guardar la URL, cada registro completado enviará una solicitud POST con todos los valores (Cliente, Teléfono, Montos, Fechas, Estado) a tu hoja de cálculo.

Guía de Integración con Google Sheets

Sigue estos sencillos pasos para vincular tu archivo de Sheets

1 Crea los Encabezados en tu Google Sheet

Abre un libro nuevo en Google Sheets y en la primera fila (Fila 1) coloca los nombres de las columnas en este orden exacto:

A B C D E F G H I J
Fecha Registro Cliente Teléfono Fecha Evento Tipo Renta Monto Total Anticipo Saldo Restante Estado Pago Observaciones

2 Copia el código en Apps Script

En tu hoja de Google Sheets, dirígete al menú superior: Extensiones > Apps Script. Reemplaza el código existente con la siguiente función doPost(e):

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // Inserta una fila con los campos exactos recibidos desde Quinta Bugambilia
    sheet.appendRow([
      new Date(),                 // Columna A: Fecha y hora de registro
      data.nombre,                // Columna B: Nombre del cliente
      data.telefono,              // Columna C: Teléfono / WhatsApp
      data.fecha,                 // Columna D: Fecha del evento
      data.tipoRenta,             // Columna E: Tipo de renta
      data.montoTotal,            // Columna F: Monto Total
      data.anticipo,              // Columna G: Anticipo
      data.restante,              // Columna H: Saldo Restante
      data.estadoPago,            // Columna I: Estado del pago
      data.notas || 'Sin notas'   // Columna J: Observaciones
    ]);
    
    return ContentService
      .createTextOutput(JSON.stringify({ "result": "success" }))
      .setMimeType(ContentService.MimeType.JSON);
      
  } catch (error) {
    return ContentService
      .createTextOutput(JSON.stringify({ "result": "error", "error": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

3 Despliega como Aplicación Web (Configuración de acceso)

  1. En el menú superior de Apps Script, presiona el botón azul Implementar > Nueva implementación.
  2. Haz clic en el ícono de engrane ⚙️ y selecciona Aplicación web.
  3. En Ejecutar como: Selecciona "Yo (tu correo)".
  4. En Quién tiene acceso: Selecciona "Cualquier persona" (Anyone). (Indispensable para aceptar peticiones web sin autenticación previa).
  5. Haz clic en Implementar, otorga los permisos solicitados y **copia la URL ejecutable de la Aplicación Web**.
